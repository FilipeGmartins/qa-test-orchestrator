# Automação (fase 5)

Diretório reservado ao runner Playwright/TypeScript. Não existe runner nesta entrega.
O worker receberá configuração JSON validada e catálogo confiável. A API usará
ITestRunner na Application e PlaywrightTestRunner na Infrastructure. Não aceitar
shell, caminhos livres ou código executável fornecido pela interface.

Testes E2E da própria plataforma ficam em frontend/e2e; não são execuções orquestradas.
